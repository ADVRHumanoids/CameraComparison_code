# Bundled rendering fonts

Liberation Serif Regular, Bold, Italic and Bold Italic are the unchanged font
files used for the verified paper figures, copied from the Debian
`fonts-liberation` installation. Copyright notices and the SIL Open Font License
are included in `LICENSE.txt`.

The renderer registers these fonts automatically. DejaVu Sans and its variants
are loaded from the pinned Matplotlib installation. No system installation or
font download is required. Keep this folder when copying the reproduction code.
